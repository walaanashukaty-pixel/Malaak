MALAAK V6.1 - START HERE

1. Extract this ZIP completely.
2. Open the extracted folder.
3. Double-click: UPLOAD_TO_GITHUB.bat
4. If GitHub opens a browser sign-in window, sign in to walaanashukaty-pixel.
5. After upload succeeds, the script opens GitHub Actions automatically.
6. The Android build will run in GitHub cloud. When it finishes, download the artifact named malaak-android-apk.

Repository already configured in the launcher:
https://github.com/walaanashukaty-pixel/Malaak

No GitHub password or token is stored in this package.
Flutter does NOT need to be installed on this computer for the GitHub Actions cloud build.
