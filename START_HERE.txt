MALAAK V6.8 - START HERE

WHAT IS NEW
===========
- The active feminine-intelligence route is now a real Skill Tree: only the current node is actionable and future nodes are visibly locked.
- Finishing an in-app session assigns a real-life mission; it does NOT unlock the next main node.
- Main follow-up opens after a configurable delay; V6.8 defaults to 18 hours.
- While waiting, the user still gets an immediate optional mini-practice and Situation Lab access.
- A successful real-life follow-up marks the node mastered and unlocks the next node.
- "ما إجتني فرصة" opens a substitute simulation instead of punishing/resetting progress.
- difficult / old-pattern / forgot outcomes go through repair/retry instead of false mastery.
- When a base route is mastered, a new advanced chapter opens instead of ending the app.
- Home prioritizes the active Skill Tree. Other Malaak domains remain visible in the life map but are locked instead of exposing every legacy short flow at once.
- Assessment remains conversational with السابق / التالي and user-controlled route choice after Malaak's recommendation.

SAFE GITHUB UPLOAD
==================

2. Double-click UPLOAD_TO_GITHUB.bat.
3. Complete GitHub browser sign-in if requested.
4. Wait for SUCCESS.
5. GitHub Actions opens automatically. Wait for Android Release Build to become green.
6. Download artifact malaak-android-apk and install app-release.apk.
