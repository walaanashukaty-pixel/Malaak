SAFE GITHUB UPLOAD
==================
1. Extract this ZIP into a NEW folder.
2. Double-click UPLOAD_TO_GITHUB.bat.
3. If GitHub opens a browser sign-in, finish the sign-in.
4. Wait for the SUCCESS message.
5. The script opens GitHub Actions automatically so you can watch the Android build.
